# 업무보고 자동수집 설정 — 「이름=값」 한 줄에 하나. # 으로 시작하는 줄은 설명이라 읽지 않습니다.
# 비워 두면 기본값을 씁니다. 고친 뒤 저장(메모장: 파일 → 저장)만 하면 됩니다.

# Online 사서함(회사 메일 계정)에서 읽을 폴더. 영어 · 한국어 Outlook 모두 같은 폴더를 찾습니다.
#   받은보낸      = 받은 편지함 · 보낸 편지함 두 폴더만 (기본)
#   받은보낸하위  = 두 폴더와 그 아래 하위 폴더까지 (규칙으로 받은 편지함 아래 폴더에 메일을 옮겨 두는 경우)
#   전체          = 모든 메일 폴더 (지운 편지함 · 정크 메일 · 아래 제외폴더는 뺌)
# .pst(Local 백업)는 이 값과 상관없이 모든 메일 폴더 · 하위 폴더를 읽습니다.
Online폴더=받은보낸

# Outlook 에 아직 안 열린 .pst 를 자동으로 잠깐 열 폴더. 비워 두면 Outlook 왼쪽에 이미 열린 데이터 파일만 읽습니다.
# 예) PST폴더=D:\메일백업   (늘 Outlook 에 열어 두면 비워 두세요)
PST폴더=

# 읽지 않을 Outlook 폴더 이름(쉼표로 구분). 지운 편지함 · 정크 메일은 적지 않아도 늘 뺍니다.
제외폴더=임시 보관함, 보낼 편지함, Drafts, Outbox, RSS 피드, RSS Feeds, 동기화 문제, Sync Issues, 대화 기록, Conversation History

# 결과를 저장할 곳. 비워 두면 「문서\업무보고_수집」 아래에 기간별 폴더를 만듭니다.
저장위치=

# 첨부 파일 한 개의 최대 크기(MB). 이보다 크면 이름 · 크기만 적습니다.
첨부최대MB=30

# 이보다 작은 그림(KB)은 서명 로고로 보고 뺍니다.
작은그림KB=15

# 한 번에 모을 최대 메일 수
최대메일수=5000

# 한 주의 시작 요일(월 또는 일)
주시작=월

# 첨부 원본을 수집 폴더에 남길지(예 · 아니오). 아니오면 글만 뽑고 원본은 지웁니다(PDF 는 도구가 읽어야 해서 남김).
첨부저장=예

# 자동으로 열 때 함께 넘길 PDF 의 최대 합계(MB). 넘으면 도구에서 「수집 폴더 열기」로 고르면 읽습니다.
PDF포함MB=60
