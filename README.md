## 어느 컴퓨터에서 실행하나요

**회사 Outlook 을 쓰는 그 회사 PC 에서 실행합니다.** 클래식 Outlook 이 설치되고 회사 계정으로 로그인되어 있어야 합니다.
수집기는 그 PC 의 Outlook 에게 메일을 물어서 읽으므로, Outlook 이 없는 PC 에서는 메일을 읽을 수 없습니다. 메일은 그 PC 밖으로 나가지 않고, 보고서 화면(브라우저)도 같은 PC 에서 열립니다.
Outlook 은 평소처럼 켜 두면 됩니다. 수집기는 켜져 있는 Outlook 에 붙어서 읽고, 꺼져 있으면 「Outlook 을 먼저 켜 주세요」라고 알리고 끝납니다(새로 띄우지 않음).

## 처음 쓰는 법 (회사 PC · Windows · 클래식 Outlook)

1. **ZIP 받기** — [전체 파일 ZIP](https://github.com/aebonlee/data09-27/archive/refs/heads/main.zip)(로그인 필요 없음) 또는 저장소 화면의 초록색 「<> Code」 → 「Download ZIP」.
2. **차단 해제 후 압축 풀기** — 받은 `data09-27-main.zip` 을 오른쪽 클릭 → 「속성」 → 아래쪽 **「차단 해제」에 체크** → 「확인」. 그다음 오른쪽 클릭 → 「압축 풀기」로 원하는 곳(예: `문서\업무보고`)에 풉니다.
   (차단 해제를 하지 않으면 3번에서 「Windows 의 PC 보호」 · 「게시자를 확인할 수 없습니다」 창이 뜹니다. 그때는 「추가 정보 → 실행」 또는 「실행」을 누르면 됩니다.)
3. **클래식 Outlook 켜 두기** — 평소처럼 켜 둔 상태면 됩니다. Online 사서함과 백업 .pst(왼쪽 목록의 데이터 파일)가 보이면 됩니다.
4. **`주간보고.bat` 더블클릭** (월간은 `월간보고.bat`) — 검은 창이 뜨고 「1) 이번 주 · 2) 지난 주」를 묻습니다. 번호를 누르고 Enter(그냥 Enter = 이번 주).
   메일을 모으는 동안 폴더별 메일 수가 나옵니다. 메일이 많으면 몇 분 걸릴 수 있습니다.
5. **보고서가 열립니다** — 다 모으면 브라우저(크롬 · 엣지)에 업무보고 도구가 열리고 모은 메일이 들어가 있습니다. **「보고서 만들기」** 를 누르면 「06 보고서」에 주간보고 양식 표(Business Group · 프로젝트 · 금주 실적 · 차주 계획)가 나옵니다. 「확인 필요」 표시를 살펴 고친 뒤 **Word(.docx) · Excel · 인쇄** 로 내려받습니다.

### 처음 한 번 — 무엇을 읽는지만 확인(-ListOnly, 저장 안 함)

1. Outlook 이 켜져 있는지 확인합니다.
2. 압축 푼 폴더를 탐색기로 열고, 위쪽 주소창에 `powershell` 을 치고 Enter.
3. 아래 한 줄을 붙여 넣고 Enter → 「1) 이번 주 · 2) 지난 주」 번호를 누르고 Enter.

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\collector\Collect-OutlookMail.ps1 -Mode weekly -ListOnly
```

4. 나온 데이터 파일 · 폴더 목록 · 폴더별 메일 수 · 걸린 시간(오류가 있으면 그 문장)을 알려 주세요. 메일 내용은 보내지 마세요.

### 보고 단계 — 팀원 → 파트리더 → 팀장 → 담당 임원

| 누가 | 하는 일 |
|---|---|
| 모두 | 「01 보고 설정」에서 작성자 · 보고 단위(예: 디자인팀 A파트) · **보고 단계** 를 한 번 정함 |
| 팀원 | 위 다섯 단계로 보고서를 만들고 「06 보고서」의 **「보고서 파일(.json) — 파트리더에게」** 를 내려받음 → 뜨는 안내대로 Outlook 메일에 첨부해 보냄 |
| 파트리더 | `주간보고.bat` 로 메일을 모으면 팀원이 보낸 보고서 파일을 **받은 메일 첨부에서 자동으로 찾음** → 「08 보고서 취합」의 **「받은 메일에서 찾은 보고서 파일 N개 불러오기」** → 같은 주간보고 양식으로 한 장(문장 앞에 [보고자], 보고자별 현황, 확인 필요 표시 그대로). 내 메일 보고서도 함께 넣을 수 있음. 「취합 보고서 파일 — 팀장에게」도 메일로 |
| 팀장 | 파트리더들의 취합 파일을 같은 방법으로 불러와 팀 보고서 → 담당 임원에게는 **「임원 보고용(요약)」** (임시 양식 — 실제 임원 보고 양식을 받으면 맞춥니다) · Word · Excel |

**메일로 주고받기(2026-09-30 답변)** — 수집기는 받은 메일의 첨부 .json 중 이 도구가 만든 보고서 파일(형식 표시 `p27-report-file-v1`)만 알아보고, `첨부저장=아니오` 로 두어도 그 파일은 남깁니다. 보낼 때 뜨는 안내 창의 「제목을 채운 새 메일 열기」는 제목 · 본문만 채웁니다 — 메일 링크(mailto)로는 파일을 첨부할 수 없어 파일은 직접 첨부합니다. 파일을 공유 폴더로 받았다면 「08」에서 직접 골라 넣으면 됩니다.

**임원 보고용(요약)** — 파트마다 건수(실적 · 계획 · 이슈 · 확인 필요)와 핵심 실적 · 주요 이슈 · 다음 주 계획을 3건씩 뽑은 한 장(Word · HTML). 실제 임원 보고 양식을 받기 전까지 쓰는 **임시 양식**이며 문서에 그렇게 적혀 있습니다.

보고서 파일에는 보고 문장 · 상태 · 프로젝트 · 근거 메일의 날짜와 제목만 들어 있고, 메일 본문 · 첨부 글은 들어 있지 않습니다. 서버 · DB 없이 파일로만 주고받습니다. 기간이 다른 파일은 빼고 이유를 알려 줍니다.

## 어떻게 동작하나요 (솔직한 설명)

**웹페이지(브라우저)는 Outlook 이나 .pst 파일을 직접 읽을 수 없습니다.** 브라우저는 보안상 사용자가 고른 파일만 읽을 수 있고, 내 PC 의 프로그램(Outlook)에 들어갈 수 없습니다.
Microsoft Graph API 를 쓰면 서버에서 메일을 읽을 수 있지만 회사 IT 의 승인이 필요하고(승인 여부 모름), .pst 는 Graph 로도 읽지 못합니다.

그래서 두 부분으로 나눴습니다.

```
 주간보고.bat  ──▶  수집기(PowerShell, 내 PC)  ──▶  수집 폴더  ──▶  업무보고 도구(브라우저)  ──▶  보고서
 (더블클릭)        클래식 Outlook 에 연결(COM)       manifest.json      보고서 만들기               Word · Excel
                   Online 사서함 + 열린 .pst          첨부 원본 · 글     실적 · 계획 · 이슈 · 양식 표
                   기간 안 메일 · 첨부 글 뽑기                           (AI 는 선택)
```

- **수집기** `collector/Collect-OutlookMail.ps1` — Windows 에 기본으로 있는 PowerShell 로 돌아갑니다(설치 없음). 클래식 Outlook 의 COM(프로그램끼리 이야기하는 통로)으로 **읽기만** 합니다.
- **업무보고 도구** `index.html` — 브라우저에서 돌아가는 페이지입니다. 설치 · 서버 · 인터넷이 필요 없습니다.

- **업무 문장** — 회의록 · 발표자료의 「~ 완료」「~ 예정」「~ 지연 · 확인 필요」 문장을 실적 · 계획 · 이슈로 뽑고 **「첨부 근거」** 로 표시합니다(같은 메일 본문과 겹치면 뺌).
- **결과물 배포일** — 첨부에 적힌 「배포일 · 발행일」, 또는 내가 결과물을 첨부해 보낸 메일의 날짜.
- **디자인 결과물 이미지** — 근거 메일에 붙은 그림 · 일러스트 파일 이름.
- **프로젝트 판정 · AI 프롬프트** — 첨부 글도 키워드 판정과 AI 프롬프트(발췌)에 들어갑니다.

## 보안 — 메일은 이 PC 밖으로 나가지 않습니다

- 수집기는 인터넷 · 서버에 연결하지 않습니다. Outlook 과 내 PC 파일만 씁니다. 메일을 옮기거나 지우거나 「읽음」으로 바꾸거나 보내지 않습니다(테스트가 이런 호출이 없는지 검사합니다).
- 모은 메일 · 첨부는 내 PC 의 수집 폴더(기본 `문서\업무보고_수집`)에만 저장됩니다. 필요 없어지면 그 폴더를 지우면 됩니다.
- 도구는 메일을 브라우저 안에서만 읽고, 이 브라우저의 저장소(localStorage)에만 둡니다.
- **밖으로 나가는 경우는 하나뿐입니다** — 「01 보고 설정 → AI 연결 설정」에 AI 서버 주소를 직접 넣고 「설정한 AI 서버로 보내기」를 누를 때, 그 주소로만 보냅니다. **사내 LLM 을 권합니다** — 사내망 안에서 끝납니다. 모델 칸에는 답변받은 **qwen3.8** 이 기본으로 들어 있고, 주소(…/v1)는 사내 IT 에 확인이 필요합니다. 주소를 넣은 뒤 「모델 목록 불러오기」로 서버에 올라간 정확한 이름을 확인합니다(예: Ollama 는 `qwen3:8b`). Qwen3 가 답 앞에 붙이는 생각하는 부분(`<think>…</think>`)은 도구가 떼고 답만 읽습니다. 키는 도구 화면에만 적습니다(코드에 없음). 설정 전에는 프롬프트를 복사해 붙여 넣는 반자동입니다.
- 보고서 파일(.json)은 사용자가 직접 메일에 첨부하거나 공유 폴더에 둘 때만 전달됩니다. 이 도구는 메일을 보내지 않습니다.

### 수강생 PC 에서 확인이 필요한 것

개발 PC 는 macOS 라 **실제 Outlook 에 붙는 부분은 돌려 보지 못했습니다.** 대신 Outlook 과 같은 모양의 가짜 객체로 수집기를 끝까지 돌려(함정 메일 포함) 결과가 예시와 같은지 확인했고(`test/pwsh/Run-MockCollect.ps1`), 워드 · PPT · 엑셀 글 뽑기는 PowerShell 과 브라우저 쪽이 같은 글을 내는지 대조했습니다(`collector/Test-Collector.ps1`).
실제 PC 에서만 확인되는 것: Outlook 날짜 거르기(Restrict)의 날짜 형식(안 맞으면 자동으로 훑기로 대신함), 회사 Exchange 주소 → 메일 주소 바꾸기, Outlook 보안 확인 창, .pst 잠깐 열기, 메일이 아주 많을 때의 속도. **처음 한 번 `-ListOnly` 로 돌려 폴더별 메일 수를 봐 주세요.**
